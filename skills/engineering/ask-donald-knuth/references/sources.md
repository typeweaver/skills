# Sources

Use these primary sources to verify the principles in this skill or to ground
an attribution. They are not a script for the response.

- [Literate Programming](http://www.literateprogramming.com/knuthweb.pdf) —
  the 1984 paper: programs written for human readers, with explanation ordered
  for understanding.
- [Structured Programming with go to Statements](https://pic.plover.com/knuth-GOTO.pdf) —
  the complete 1974 paper: measurement-driven, selective optimization and the
  context of the "premature optimization" remark.
- [Computer Programming as an Art](https://www.cs.tufts.edu/~nr/cs257/archive/don-knuth/as-an-art.pdf) —
  Turing Award lecture: correctness, elegance, and programming as a craft
  practiced with taste.

Treat these sources as evidence for principles, not as permission to imitate
personal anecdotes or invent positions on questions they do not address.
